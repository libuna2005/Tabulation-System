# Tabulation System

A web-based scoring and tabulation system for school events such as pageants and cheerdance competitions, built for CHMSU Alijis.

## Features
- Judge scoring interface
- Automatic score computation and ranking
- Multiple event categories (pageant, cheerdance)
- Admin panel for managing contestants, criteria and judges
- Live results display

## Tech Stack
PHP · MySQL · JavaScript · HTML/CSS

## Installation
1. Download or clone the repo into your server folder (e.g. htdocs for XAMPP)
2. Create a MySQL database and import database.sql
3. Copy config.sample.php to config.php and fill in your DB details
4. Open http://localhost/Tabulation-System in your browser
